# localize-it-corpus — Mycelium Hive shared mesh corpus

**Privacy rule:** This directory contains only **anonymous, shareable** material:
system conventions, architecture patterns, frameworks, and generic voice guidance.

**Do not commit here:** personal names, contact information, work-application
details, raw chat logs, or operator-specific priorities. Those belong to the
`private` / `sealed` tiers and are stored node-locally under
`~/.mycelium/localize-it-corpus/`.

The `contexts/` and `feedback/` subdirectories are intentionally empty except
for `.gitkeep`. Captures that used to live here and contained personal context
have been removed from Git history.

See `~/grove-commons/SPECS/mycelium-privacy-tiers-and-pii.md` for the full
privacy and PII-handling specification.
